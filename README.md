# QuickNotes

QuickNotes is a simple note-taking web application built with HTML, CSS and JavaScript. It allows users to create notes, choose a category, search through their notes, delete notes and keep their notes saved in the browser using localStorage.

## Features

- Add notes
- Choose Personal, Work or Study categories
- Validate empty notes
- Limit notes to 200 characters
- Display the date and time each note was created
- Delete individual notes
- Search notes
- Display the number of notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive design for smaller screens
- Different visual styles for each category

## How to Run Locally

1. Clone or download this repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in a web browser.

You can also use the Live Server extension in Visual Studio Code to run the project.
